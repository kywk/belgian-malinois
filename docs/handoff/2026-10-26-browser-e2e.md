## 發現與修正

- 候選任務缺少認領入口：待辦標示「待認領」，詳情先顯示認領；成功後重新取得伺服器狀態才開放核決與批註。競爭認領失敗時清除舊狀態並重查，避免本機假指派。
- blur 驗證使錯誤訊息區縮短，可能在按下與放開滑鼠之間移走下一個控制項：宿主填答表單預留錯誤區域，超長訊息可捲動，未修改 SDK。已用瀏覽器重跑「數量 11 被擋 → 改成 3 → 立即點送出」，第一次點擊成功；錯誤消失後單選第一次點擊也正常。
- 登出選單未指定 index 造成 Element Plus 事件警告：提供有效 index 與首頁路由，實際登出／登入重驗無警告。
- 申請清單載入失敗向 mounted hook 拋出未處理錯誤：顯示錯誤及重試入口，以請求序號避免分頁切換時舊回應覆蓋新狀態；失敗與重試由回歸測試驗證。
